    INTERNSHIP

    インターンシップ・
    仕事体験を知る

    2025年卒から、インターンシップは4つのタイプに分けられました。参加して得た情報が採用選考に使われるのは、タイプ3とタイプ4だけ。申し込む前に、どのタイプかを確かめましょう。

    4つのタイプを見る
    1. TYPE 1オープン・カンパニー選考利用 不可
    2. TYPE 2キャリア教育選考利用 不可
    3. TYPE 3汎用的能力・専門活用型インターンシップ選考利用 可
    4. TYPE 4高度専門型インターンシップ（試行）選考利用 可

    EVENT

    説明会・イベント

    3月の広報解禁から本格的に始まる説明会。種類ごとの特徴を知って、自分に合うものを選びましょう。

    JOINT合同企業説明会1日で多くの会社の話が聞ける COMPANY単独企業説明会1社をくわしく知る CAMPUS学内企業説明会大学に会社が来てくれる

    BY GRADE

    いま、やること

    学年ごとに、この時期にやっておきたいことを3つにしぼりました。

    大学1・2年生29卒・30卒

    • 気になる業界をなんとなく知る
    • オープン・カンパニー（タイプ1）で会社の雰囲気を見る
    • アルバイト・サークル・学業で「自分が頑張れること」を探す

    大学3年生28卒

    • 自己分析と業界研究を始める
    • 秋冬のインターンシップに応募する
    • 3月の広報解禁までにESとWebテストの準備をする

    大学4年生27卒

    • 10月1日以降の正式な内定を確認する
    • 内定先を選ぶ・承諾する
    • 入社までの過ごし方を決める
