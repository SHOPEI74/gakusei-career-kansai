BY GRADE

いま、やること

学年ごとに、この時期にやっておきたいことを3つにしぼりました。

大学1・2年生29卒・30卒

  • 気になる業界をなんとなく知る
  • オープン・カンパニー（タイプ1）で会社の雰囲気を見る
  • アルバイト・サークル・学業で「自分が頑張れること」を探す

大学3年生28卒

  • 自己分析と業界研究を始める
  • 夏・秋冬のインターンシップに応募する
  • 3月の広報解禁までにESとWebテストの準備をする

大学4年生27卒

  • 10月1日以降の正式な内定を確認する
  • 内定先を選ぶ・承諾する
  • 入社までの過ごし方を決める

INTERNSHIP

そのインターン、
選考に関係ある？

2025年卒から、インターンシップは4つのタイプに分けられました。参加して得た情報が採用選考に使われるのは、タイプ3とタイプ4だけ。申し込む前に、どのタイプかを確かめましょう。

4つのタイプを見る
  1. TYPE 1オープン・カンパニー選考利用 不可
  2. TYPE 2キャリア教育選考利用 不可
  3. TYPE 3汎用的能力・専門活用型インターンシップ選考利用 可
  4. TYPE 4高度専門型インターンシップ（試行）選考利用 可

選考対策

自己分析からES、Webテスト、面接まで。選考の流れの順に並べています。

STEP 1自己分析強みと価値観を言葉にする STEP 2ガクチカ学生時代に力を入れたこと STEP 3エントリーシート結論から短く書く STEP 4WebテストSPI・玉手箱などの形式 STEP 5グループディスカッション役割より議論への貢献 STEP 6面接深掘りに答えられる準備
